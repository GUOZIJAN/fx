# FX 简单!

一款简约可爱的外汇模拟交易网页游戏。打开 `dist/index.html` 即可游玩；建议用本地 HTTP 服务器运行，以便读取真实历史数据。

## 玩法

- 七种货币对；可切换模拟数据行情、真实历史汇率回放、经典战役与每日挑战。
- 投入保证金，选择 1–100 倍杠杆，做多或做空；可手动平仓。
- 当单笔仓位亏损达到保证金的 60% 时弹出风险提醒，可直接追加保证金或借款补仓；达到 80% 后若仍未补足则自动爆仓。
- 可借入最多 $200,000；日利率按单笔借款金额分级：不超过 $10,000 为 0.01%，不超过 $50,000 为 0.02%，不超过 $100,000 为 0.03%，更高为 0.04%。历史模式每推进一个交易日计息；模拟数据每 30 秒计息一次。可提前还款，还清后可再次借入。
- 首次进入可选择新手教程；之后也可随时从页面顶部重新打开。
- 四场经典战役：2015 年瑞郎脱钩、2016 年英国公投、2022 年欧元接近平价与日元干预。可逐日推进、自动播放或回到起点。
- 每次打开游戏都从模拟数据模式开始，开屏即可交易；其他模式的资金与回放进度保留，切换时自动续播。
- 游戏进度保存在当前浏览器的本地存储中；"重新开始"可清空当前模式的进度。

## v3 新增

- **设置**：顶栏 ⚙ 打开。音效开关与音量（WebAudio 合成，零资源体积）；音乐开关与音量，音乐不内置、由玩家导入本地音频文件（IndexedDB 保存 1 首，约 15MB 上限，可试听/清除）；市场新闻开关与三档频率；白天 / 夜间主题。
- **新闻中心**：市场快讯改为图表下方跑马灯 + 右上角滑入卡片，居中大弹窗只留给风险提醒与结算；"新闻中心"可回看本次会话全部快讯（含战役历史快讯）。
- **K 线统一**：真实数据与经典战役与模拟行情一样绘制蜡烛图。日度参考汇率没有盘中高低点，影线为示意并在图例标注；真实/战役支持 日 / 周 / 月 周期切换与可拖动的回放进度条。
- **真实数据区间**：可自选起止日期（快捷档 30/90/180/365/600 天、今年，或自定义日期，跨度上限 600 天），显示交易日数量与区间统计（最高/最低/振幅/涨跌），每个区间分别记住回放进度；回放结束会给出"买入持有"对照。
- **成就系统**：12 枚成就（"fx，简单！""现在买入，一定爆赚""手指支撑线""不卖就不算亏""杀就杀吧""被瑞士杀死了""本喵明明没做坏事""最对不起的就是家人""我有必胜法""老实赚钱，很枯燥吧""天台见""感谢支持喵"），顶栏 🏆 打开成就册；B站 App 内会真实校验关注状态，进度支持云存档同步。
- **战绩分享卡**：顶栏 📤 生成专属战绩卡（久留美头像、权益与收益、胜率、成就进度、权益曲线），B站 App 内可直接保存到相册、分享给好友，卡片自带打开游戏的二维码；网页端提供图片下载。

真实数据来自 [Frankfurter](https://frankfurter.dev/)，属于历史日度参考汇率，不是实时交易报价。所有交易、贷款和盈亏均为游戏模拟，不涉及真实资金。

## 独立联机版

联机版的前端单独打包为 B站 Toy，服务器仅通过 HTTPS/WSS 提供联机 API，不提供游戏页面。全服共享由玩家和机器人订单推动的行情；账户、每日重开次数、排行榜和爆仓人数由独立服务器保存，与单机版数据互不影响。源码与部署说明见 [online/README.md](online/README.md)。
