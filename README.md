# FX 简单!

一款简约可爱的外汇模拟交易网页游戏。在线游玩：[GitHub Pages](https://guozijan.github.io/fx/)。网页版本位于 [`docs/`](docs/)，无需账号或专用客户端。

## 玩法

- 七种货币对，可切换模拟行情、真实历史汇率、经典战役和每日挑战。四场经典战役包括 2015 年瑞郎脱钩、2016 年英国公投、2022 年欧元接近平价与日元干预。
- 使用保证金和 1–100 倍杠杆做多或做空，支持手动平仓。接近爆仓时可追加保证金或借款补仓；价格跳空可能造成穿仓。
- 贷款上限 $200,000，借款越多日利率越高。历史模式按交易日计息，模拟模式每 30 秒计息一次。
- 每日挑战初始本金 $10,000，每个浏览器每天可开始三次。点击“金盆洗手”结算，成绩保存到本机记录。
- 模式之间的资金和进度独立；可查看成就、分享战绩卡、切换主题和音效，首次进入可打开新手教程。

游戏进度、成就和挑战记录仅保存在当前浏览器。更换设备或清除网站数据后无法恢复；每日挑战次数也随浏览器数据重置。真实数据来自 [Frankfurter](https://frankfurter.dev/)，属于历史日度参考汇率，不是实时交易报价。所有交易、贷款和盈亏均为游戏模拟，不涉及真实资金。

## 本地运行

在仓库根目录启动静态文件服务器，并打开 `docs/` 对应的网址。例如：

```sh
python -m http.server 8000 --directory docs
```

然后访问 `http://localhost:8000/`。直接打开 `docs/index.html` 也可体验模拟行情；真实数据需要网络连接。
