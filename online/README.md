# 大A 简单! 联机版

本目录是独立于根目录 `dist/` 单机外汇版的 A 股模拟交易游戏。前端放在 B站 Toy，服务器只提供 API 与 WebSocket。股票代码及名称取自 A 股，所有报价均为游戏中玩家与机器人委托撮合产生的模拟价格，不是真实行情，也不执行实盘 T+1 或 100 股整数手规则。

## 运行和构建

后端需要 Python 3.11+：

```bash
cd online
python -m pip install -r server/requirements.txt
cd server
python -m uvicorn app:app --host 127.0.0.1 --port 8788
```

在 `online` 执行 `python build_toy.py`，会将 `web/` 复制到 `toy/` 并写入 Toy 使用的 HTTPS 后端地址。`web/config.js` 是本地调试用的地址，不会打入 Toy。服务器部署的 SQLite 文件是 `A_SHARE_DATA/a-share.sqlite3`，与旧联机外汇数据库 `game.sqlite3` 隔离。

## 游戏规则

- 三只股票：东方财富 300059、宁德时代 300750、中际旭创 300308。14 个机器人持续向买卖盘挂单、吃单，低在线人数时也能撮合。机器人每档提供约 ¥6–9 万的双向流动性，并围绕玩家交易形成的参考价报价；价格越低，每档换算的股数越多，仍能维持对手盘。
- 玩家主动成交按买卖方向和成交金额持续推动参考价；大额成交的边际影响逐渐减弱，但没有每分钟净影响上限、初始价保护区间或强制回归初始价。最终价格仍由委托簿上的实际撮合确定。机器人自己的成交不会把下一轮报价中心机械地推高。
- 机器人接单前会比较成交价与稳健参考价：优先取买一、卖一的中间价，排除正在撮合的两笔委托；盘口缺失、交叉或明显偏离成交行情时，改用最近 21 个有成交的秒线收盘价中位数（至少 5 个）。候选成交价、机器人自身报价、最近成交价都必须落在参考价附近 8% 内（低价股至少保留一分钱跳动），否则机器人跳过该单。机器人报价优先跟随已经形成的成交中位价；成交价与参考价断层时暂不接单，让真人继续发现价格。爆仓判断也使用稳健参考价，避免单笔异常成交瞬间触发强平。
- 当价格跌到几分钱时，机器人使用同价位的双向挂单并避免机器人挂单互相成交，防止价格四舍五入后买卖盘消失；低价时不再由机器人主动吃单推动跳价。实际成交仍由玩家委托或对手盘产生。
- 最小成交与限价档位为 ¥0.01；服务启动时自动修正旧版本产生的零元当前报价、撤销零元待成交委托，并保留账户、持仓和已结算记录。
- 2026-10 的低价故障采用 `server/rebase_market.py` 一次性恢复：旧持仓按停服时市价无手续费结算，未成交委托撤销，余额与已结算交易历史保留，旧 K 线移到 `candle_bars_archive`，新图从恢复后的初始价开始。脚本默认只显示预计结算数据；在停服并备份数据库后才可使用 `--apply`，重复执行会拒绝。
- 市价单依对手委托的价格、时间顺序成交；限价单有未成交部分时挂在委托簿。可在“我的委托”撤单。买卖和市价、限价平仓都使用同一撮合机制。
- 初始 ¥10,000，保证金单笔至少 ¥20，杠杆 1–50 倍；没有单笔保证金或买卖名义金额的固定上限，但必须有足够可用余额支付保证金和手续费。同时最多五笔仓位或待开仓委托。
- 开仓与平仓均按名义金额及杠杆收手续费。亏损达到保证金的 80% 尝试强平，跳空时允许穿仓，现金可为负。
- 每个游戏账号按北京时间每天可以“重启人生”三次；每次恢复 ¥10,000，清除持仓和本轮结算记录。排行榜按实时权益排序。
- 每个登录的 B站账号通过当前 Toy 的云存储保存一个长期联机令牌，跨设备可恢复服务器账号。Toy SDK 不向服务器提供可验证的 B站登录凭证，因此这不是严格的服务端身份校验。非 Toy 的本地开发环境使用浏览器本地存储。
- 行情图支持按秒、小时、5 小时、天切换 K 线。拖动图下方时间进度条可回看历史，拖到最左侧会继续读取更早一页，点击“回到实时”恢复最新行情。后端按每笔实际撮合成交聚合开高低收，通过 `GET /api/candles` 分页读取；秒线保存最近 7 天，其他周期持续保存。历史表从本功能上线时开始积累，更早的逐笔成交没有记录，无法补出完整长周期 K 线。

## 验证与部署

在 `online/server` 执行 `python -m unittest test_ashare_engine -v`。新服务 `a-share-online.service` 使用本机 `127.0.0.1:8788`，Nginx 将 HTTPS `/a-share/` 转发给它。旧的 `fx-online.service` 和 `/fx-online/` 保持运行。Toy 包的页面资源使用相对路径。根目录单机版及其已发布 Toy 不受此目录构建影响。

性能维护：最近成交记录按玩家和交易编号建立索引，避免在线广播时反复扫描整张成交表。排行榜通过余额索引读取现金领先者，并逐一计算持仓玩家的权益，避免每轮扫描全部账号。交易接口完成撮合后立即返回，行情推送在后台合并执行、最多每秒一次；定时广播批量构造快照，并行发送给连接，新玩家连接时只发送自己的首帧。

服务器上的 Let's Encrypt IP 证书由 `fx-certbot-renew.timer` 续期。新服务数据文件：`/opt/a-share-online/data/a-share.sqlite3`；旧联机 FX 存档仍是 `/opt/fx-online/data/game.sqlite3`。
